# Guitarrero

Software desktop para Windows, 100% local, para estudar uma música com o próprio equipamento:

- **Módulo Timbre** (ex-Timbrador Profissional / Tone Lab Pro): regulagem dos 9 equipamentos da bancada, simulação do timbre e calibração por amostras gravadas.
- **Módulo TAB** (ex-TAB Simplifier Pro): simplificação de tablaturas e treino no estilo Yousician.

Status: Etapa 3 (setup do repositório) ainda não iniciada. Plano, decisões e riscos em `docs/guitarrero/05_PLANO_MESTRE_DECISOES_E_RISCOS.md`.
